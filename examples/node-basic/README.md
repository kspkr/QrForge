# Node.js: generate QR code files

Generates an SVG, a styled PNG, a labelled A4 PDF for a Wi-Fi network and a contact card with
[`@qrforge/core`](../../packages/core), then prints a scan reliability report. Everything runs
offline.

```bash
cd examples/node-basic
npm install
node index.js
```

Output is written to `out/`.

Requires Node.js 18 or newer.
